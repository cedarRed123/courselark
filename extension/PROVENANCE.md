# CourseLark source and asset provenance record

This inventory records what is bundled and what still needs a rights review. It does not prove independent authorship or legal clearance.

| Material | Present source | Current attribution / license basis | Remaining check |
| --- | --- | --- | --- |

On October 19, `../tools/verify-vendor.py` compared all 21 bundled vendor files and notices with installed `pdfjs-dist` 6.4.299 and `fflate` 0.8.3 packages using SHA-256. The first pass found that the bundled fflate MIT notice used the older 2023 copyright year, while the 0.8.3 package and [upstream license](https://github.com/101arrowz/fflate/blob/master/LICENSE) use 2026. The bundled notice was replaced with the exact package file. The repeat comparison passed for every listed file, including both PDF.js modules, the fflate browser module, both top-level dependency notices, and all bundled font files/notices. This verifies correspondence to those installed packages, not ownership of project-specific code or full license compliance.

To repeat with independently installed packages, run `python3 tools/verify-vendor.py --pdfjs-dir /path/to/pdfjs-dist --fflate-dir /path/to/fflate` from the repository root. The script rejects unexpected package versions or any byte mismatch.

`REA-FINDINGS.md` documents inspection of the older Better Canvas repository at commit `c7d8bad4e6c2c10589f07e4497e0080a8cc2825a` (AGPL v3). That reference code is not listed among bundled files. A limited lexical comparison reported no identical original files and no exact runs of 35 or more tokens in compared application JS/CSS/HTML. The comparison cannot resolve adapted expression, visual similarity, contractual duties, or ownership. A reviewer should examine any reuse before treating the MIT declaration as cleared.

The October 19 icon revision has a reproducible vector source. Its leaf-wing bird and green field are visibly different from the older reference's orange/red “BC” ring; both 128-pixel PNGs were inspected side by side. The new icon was not derived by tracing or modifying the reference icon. This is evidence about this asset only, not a clearance of the CourseLark name, other branding, or application layout.

After `npm install` in `extension/`, run `node tools/render-icon.mjs` from the repository root to reproduce the 128×128 PNG. In this review environment, rendering twice produced the same PNG SHA-256: `22110cb77ae926a6253150acafd631518df70fe8cc6bf9da5883160bb22265c6`. The SVG source is `extension/icons/icon.svg`.

The package script in `../tools/package-extension.py` includes CourseLark runtime files and all listed notices. For future releases, record the package SHA-256, upstream dependency versions, contributor permissions, and results of the rights review alongside the release candidate.
