# Open Campus

Open Campus is an independent, local-first browser extension for Canvas dashboards, assignments, grades, planning, notes, themes, and study tools. The complete source code is in [`extension/`](extension/), with setup and development instructions in its [README](extension/README.md).

Download an installable ZIP from [Releases](https://github.com/cedarRed123/open-campus-policies/releases). Each release has a source tag and a corresponding browser-extension ZIP. To load an unpacked extension, use the `extension/` directory at the desired tag. Changes to the source require repackaging before installation.
